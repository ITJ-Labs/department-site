# 🛠️ ITJ Labs Department Site – Development & Deployment Instructions

## 🚀 Local Development Setup (macOS & Ubuntu)

Follow these steps to run the Hugo site locally and prepare for future deployment.

---

### ✅ 1. Clone the repository

```bash
git clone https://github.com/ITJ-Labs/department-site.git
cd department-site
```

---

### ✅ 2. Install Hugo (Recommended version: `v0.147.6`)

#### 🧑‍💻 macOS (via Homebrew)

```bash
brew install hugo
```

#### 🧑‍💻 Ubuntu / WSL

```bash
sudo apt remove hugo  # Remove old versions
curl -LO https://github.com/gohugoio/hugo/releases/download/v0.147.6/hugo_extended_0.147.6_Linux-64bit.tar.gz
tar -xzf hugo_extended_0.147.6_Linux-64bit.tar.gz
sudo mv hugo /usr/local/bin/
```

#### ✅ Confirm installation

```bash
hugo version
# Should output: hugo v0.147.6+extended...
```

---

### ✅ 3. Install PaperMod Theme

```bash
git clone https://github.com/adityatelange/hugo-PaperMod.git themes/PaperMod
```

---

### ✅ 4. Start the Development Server

```bash
./scripts/workflow.sh serve
```

This command:

* Clears old Hugo caches
* Applies custom CSS from `assets/css/`
* Generates the partial head file with `<link>` tags
* Serves the site at: [http://localhost:1313](http://localhost:1313)

---

### 📄 Project Structure Overview

```
├── assets/css/                  # Your custom CSS files
├── content/                     # Markdown content files (home, about, services, etc.)
├── layouts/partials/           # Autogenerated extend_head.html with CSS links
├── scripts/
│   ├── workflow.sh             # Main dev orchestrator
│   ├── apply-custom-css-macos.sh
│   └── serve.sh
├── static/css/                 # CSS copied here for serving
├── themes/PaperMod/           # Cloned theme
└── config.toml                 # Hugo + PaperMod configuration
```

---

## 📦 Deployment Guide (Static Hosting or GitHub Pages)

Once ready to deploy:

1. Generate production build:

   ```bash
   hugo --minify
   ```

2. Output will be in the `public/` folder:

   * Upload to a static host
   * Or push to `gh-pages` branch for GitHub Pages

---

## 🧠 Notes

* Make sure your `config.toml` has `theme = "PaperMod"` and required params.
* All CSS in `assets/css/*.css` is automatically applied via `apply-custom-css-macos.sh`.
* If Hugo warns about missing layouts, double-check that the theme was cloned correctly into `themes/PaperMod/`.
